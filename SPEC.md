# BookScanner Specifications

The product specification is separated by release:

- [Version 1 specification](./SPEC-V1.md) — core Android/iOS document and book scanning, OCR, PDF, Markdown, Word, architecture, privacy, and scanner parity.
- [Version 2 specification](./SPEC-V2.md) — specialized receipt, invoice, spreadsheet, African-market, target-size sharing, automatic redaction, education, and strict local-only features built on Version 1.

Implement Version 1 before Version 2 unless an approved delivery plan explicitly selects an independent Version 2 foundation item.
