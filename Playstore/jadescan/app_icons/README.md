# JadeScan app icons

Generated by `Playstore/jadescan_logo.swift`. Regenerate with:

```sh
swiftc -O Playstore/jadescan_logo.swift -o /tmp/jl && /tmp/jl assets/fonts Playstore/appscreens Playstore/jadescan
```

| Folder | Copy to | Notes |
|---|---|---|
| `android/mipmap-*/` | `android/app/src/main/res/mipmap-*/` | `ic_launcher.png` / `ic_launcher_round.png` are the 48 dp legacy icons (Android 7 and older). The `_foreground`, `_background` and `_monochrome` layers are 108 dp, used by the adaptive icon. |
| `android/mipmap-anydpi-v26/` | `android/app/src/main/res/mipmap-anydpi-v26/` | Adaptive icon for Android 8+, with a monochrome layer for Android 13 themed icons. Add `android:roundIcon="@mipmap/ic_launcher_round"` next to `android:icon` in `AndroidManifest.xml`. |
| `android/playstore_icon_512.png` | Play Console | Store listing icon (512 x 512, no transparency). |
| `ios/AppIcon.appiconset/` | `ios/Runner/Assets.xcassets/AppIcon.appiconset/` | Same file names as the Runner template; square and opaque, iOS rounds the corners. |
| `web/` | website / `web/` | Favicons, Apple touch icon, PWA icons (`icon-maskable-*` keeps the mark inside the 80% safe zone). |

The adaptive foreground draws the mark at 86% so the corner brackets stay inside Android's 66 dp safe circle on round launchers.
